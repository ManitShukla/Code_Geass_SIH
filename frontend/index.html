Access control

Grant Document Access

READ allows authorized retrieval. WRITE also permits contract version commits; it does not transfer ownership or provide a general file editor.

Access starts immediately. Expiry is calculated from submission time; displayed timestamps use this browser's timezone. The reason is off-chain metadata.

Access revocation

Revoke Access

Revoke this user's access?

Revocation blocks future authorized retrieval. It cannot erase copies or keys a recipient already saved. Strong revocation additionally creates a new current key and encrypted version for remaining authorized users.
