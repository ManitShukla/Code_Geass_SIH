02 / TECHNOLOGYBROWSER → STORAGE → CHAIN

ENCRYPT BEFORE
YOU UPLOAD.

The file leaves your device.
The plaintext does not.

INTERACTIVE DEMONSTRATION / NO LIVE TRANSACTIONS01 / 07

  1. Choose a document on your device. This story uses a synthetic example.

  2. Compute the plaintext fingerprint locally before encrypting.

  3. Generate a fresh file key and IV. Encrypt file bytes in your browser.

  4. Wrap the owner's AES key with their public key or the supported password mode.

  5. Send encrypted bytes, wrapped key and supporting metadata. Plaintext sent / no.

  6. In the product, MetaMask signs registration and the app awaits confirmation.

  7. The backend verifies registration before activating the asset. This is separate from a later plaintext integrity check.

SELECT / Choose a local document. Demonstration only.

03.2 / STRONG REVOCATION

REVOKE.
ROTATE.
CONTINUE.

Change who has access.
Then change the current key.

Revocation blocks future authorized retrieval. It cannot erase copies or keys a recipient already saved.
